## Working Rules

- Use `diy.md` for examples contributed by community users, such as OpenCV projects, Home Assistant/BTHome, NES, vision car, thermal imaging, tunneling, MQTT server setup, PyQt5 GPT assistant, and 1B shell designs.
- Use `update.md` for dated documentation/system changes, especially EMMC support, Android release, GPIO numbering change in WalnutPi OS v2.3, OpenCV additions, Home Assistant additions, and first release history.
- Treat community project links as references; open the linked forum/Bilibili page before giving details beyond the local summary.
- For current OS/image availability, use `intro/download.md` as the current source after reading update notes.
